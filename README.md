
# Instagram Public Downloader — v1.2

تمرکز این نسخه روی تجربه کاربری ساده است:
- یک کادر لینک
- یک دکمه دانلود
- تشخیص خودکار نوع محتوا
- پیش‌نمایش
- دکمه «دانلود فایل اصلی»
- فرمت‌ها و کیفیت‌های دیگر فقط در صورت نیاز
- پشتیبانی از چند فایل
- proxy کردن API از طریق Nginx

اجرا:

```bash
docker compose up -d --build
```

سایت:
`http://SERVER_IP:3000`

در نسخه نهایی بهتر است دامنه و HTTPS، CDN و storage اختصاصی نیز اضافه شوند.

این پروژه برای محتوای عمومی طراحی شده و شامل دسترسی به حساب خصوصی، دریافت رمز یا دور زدن کنترل دسترسی نیست.
