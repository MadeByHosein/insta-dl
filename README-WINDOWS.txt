# Instagram Public Downloader — Windows Local

این نسخه برای تست روی ویندوز و بدون Docker آماده شده است.

## پیش‌نیاز

Python 3.11 یا جدیدتر نصب باشد.

هنگام نصب Python گزینه:
Add python.exe to PATH
را فعال کنید.

## اجرا

1. فایل ZIP را Extract کنید.
2. وارد پوشه پروژه شوید.
3. روی `start.bat` دابل‌کلیک کنید.
4. مرورگر روی این آدرس باز می‌شود:

http://127.0.0.1:8000

بار اول ممکن است نصب پکیج‌ها چند دقیقه طول بکشد.

## توقف

پنجره سرور را ببندید یا `Ctrl+C` بزنید.

## نکته مهم

این نسخه برای محتوای عمومی اینستاگرام ساخته شده و برای دسترسی به حساب‌های خصوصی، ورود با نام کاربری/رمز عبور یا دور زدن محدودیت‌های دسترسی استفاده نمی‌شود.

پشتیبانی دقیق از هر URL به وضعیت و تغییرات اینستاگرام و yt-dlp بستگی دارد.


### اگر همان لینک اینستاگرام هنوز Resolve نشد

Instagram در حال حاضر برای بعضی درخواست‌های عمومی بدون نشست، پاسخ کامل رسانه را نمی‌دهد. این موضوع در گزارش‌های اخیر yt-dlp هم دیده شده، از جمله برای Carouselهای تصویری. 

برای تست روی کامپیوتر خودت:
- Chrome را نصب و با حساب خودت وارد Instagram باش.
- Chrome را کامل ببند.
- `start-with-chrome-session.bat` را اجرا کن.
- دوباره همان لینک Carousel را تست کن.

این حالت فقط برای تست محلی است و کوکی‌ها را به API ارسال یا ذخیره نمی‌کند.


### v1.5
خطای JSON parsing اصلاح شد. برای بررسی وضعیت API می‌توانی http://127.0.0.1:8000/api/diagnostics را باز کنی.


### v1.6 — دانلود خودکار همه محتوا
در این نسخه کاربر هیچ Mode یا Formatی انتخاب نمی‌کند.
یک لینک عمومی Instagram وارد می‌شود و سیستم به‌صورت خودکار عکس، ویدیو و Carousel را پردازش می‌کند. اگر چند فایل وجود داشته باشد، آن‌ها در یک ZIP قرار می‌گیرند.

برای عکس و Carousel از gallery-dl استفاده شده، چون yt-dlp در حال حاضر برای Carouselهای فقط-عکس خطای `No video formats found` دارد. این رفتار در issueهای اخیر پروژه yt-dlp نیز گزارش شده است.


### v1.7 — Direct Public Extractor
در این نسخه gallery-dl حذف شده است. استخراج‌کننده ابتدا خود صفحه عمومی Instagram را دریافت می‌کند و URLهای media عمومیِ موجود در HTML/JSON صفحه را پیدا می‌کند؛ سپس عکس‌ها و ویدیوها را به‌صورت خودکار دانلود می‌کند. کاربر همچنان فقط یک لینک و یک دکمه دارد.

محدودیت: اگر Instagram خود صفحه عمومی را به login redirect کند یا URL رسانه را در پاسخ عمومی در اختیار نگذارد، برنامه نمی‌تواند آن محتوا را بدون نشست/احراز هویت دریافت کند.
